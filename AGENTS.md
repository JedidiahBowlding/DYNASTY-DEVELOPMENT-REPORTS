# Public reporting rules

Keep this checkout limited to documentation and separately approved sanitized visual previews. Use the milestone template, distinguish verified results from assumptions, and tie aggregate evidence to the tested source revision. Publish only approved summaries. Exclude source and diffs, proprietary details, credentials, private paths, internal infrastructure, customer information, model weights and unreleased assets. Validate the entire outgoing snapshot and show the complete diff. Block any scan failure. Standing owner approval authorizes publication of sanitized text reports and status updates after each completed milestone. Require separate explicit approval for each new or changed image or other visual asset. Apply this approval only when the exact outgoing diff has been inspected and the privacy validation passes. Publish using fast-forward pushes and verify the public URL anonymously.

## Character-quality visual evidence

Every character-quality milestone needs matched before-and-after evidence for portrait, body and facial dialogue. Record candidate versions, defects, improvements, regressions and missing evidence. Publish only owner-approved cropped previews under the milestone images directory. The permitted formats are metadata-free low-resolution PNG comparison panels embedded in their own milestone report. Show the owner the exact images and outgoing snapshot before requesting approval. Keep original references, full-resolution renders, editable assets and synchronized videos private. Publication approval and visual gate approval are separate decisions.
